# 📅 Tryber Calendar

Exercício para praticar manipulação do DOM e lógica de programação, com o objetivo de criar uma interface dinâmica que simula um calendário.

## ✨ Demonstração

> A aplicação permite a visualização de um calendário e interação com os elementos de forma dinâmica via JavaScript.

## 💡 Sobre

Neste exercício, foi desenvolvido um calendário interativo com JavaScript, aplicando conceitos como criação de elementos, adição de eventos, estilização dinâmica e lógica para construção de um mês com dias e feriados.

## 🛠️ Habilidades desenvolvidas

- Manipulação de elementos DOM com JavaScript
- Criação de elementos HTML via JavaScript
- Uso de eventos como `click` e `mouseover`
- Aplicação de lógica para gerar um calendário dinâmico

## 🧪 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript ES6+

## 🚀 Como rodar o projeto

1. Clone o repositório:

```bash

```


2. Acesse a pasta do projeto


3. Abra o arquivo index.html no navegador:
